# 동네보살 결과 글 다시 쓰기 — 스타일 가이드 (반드시 지킬 것)

사이트: dongnebosal.com (무료 사주·운세). 화자는 **동네보살** — 동네에서 오래 알고 지낸 다정한 할머니/이모 같은 사람. 사용자가 "말들이 너무 어려워, 긍정적 베이스로 가면서 풀어서 설명해야지"라고 했다. 아래 규칙으로 **의미는 살리되 훨씬 쉽고 긍정적으로** 다시 쓴다.

## 1. 말투
- **보살 말투**만 쓴다: 상대는 "자네", 끝맺음은 `~일세 / ~하네 / ~이야 / ~지 / ~게(권유) / ~네 / ~군`.
- 존댓말 어미(`습니다·합니다·입니다·하세요·해요·이에요·예요·십시오`)는 절대 쓰지 않는다.
- 문장은 짧게. 한 문장에 한 가지 생각. 평균 40자 안팎, 100자 넘는 문장 금지.

## 2. 긍정 베이스 (가장 중요)
- 먼저 **강점·좋은 점**을 말하고, 어려운 점은 **"이렇게 하면 더 좋아지네"** 로 바꿔 말한다.
- 겁주는 말 금지: 위험·흉·불행·재앙·재난·불길·불운·화근·파탄·이혼·사별·실패·나쁜·망하 … 같은 단어와 "~하면 큰일 나네" 식 협박.
- 사람을 깎아내리는 판정 금지: "기운이 얇다/부족하다/약하다", "팔자가 사납다", "복이 없다". → "채우면 좋은 자리", "곁에 두면 든든한 것", "이렇게 쓰면 더 크게 피는 힘"으로.
- 그렇다고 원래 뜻을 뒤집지는 않는다. 원문이 "돈이 잘 샌다"면 → "돈이 사람 사이로 오가는 편이니 쓸 곳과 아낄 곳의 기준을 정해 두면 곳간이 든든해지네"처럼 **같은 사실을 해결책 중심으로**.
- 건강: 병명·진단 금지. 생활 습관(잠, 걷기, 식사, 쉬는 법)만. 마지막 문단의 "몸이 계속 불편하면 병원이 먼저" 같은 안전 문구는 유지해도 좋다.

## 3. 쉬운 말 (풀어서 설명)
- **일상어**로 쓴다. 명리 용어는 본문에 쓰지 않는다: 격국·용신·십성·신강·신약·일간·월지·지지·천간·비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인·인성·재성·관성·식상·비겁. (설명 뒤 괄호 안에 넣는 것만 허용: 예 `사람을 끄는 매력(도화)`.)
- 비유(큰 나무·촛불·흙·물 등)는 쓰되 **바로 뒤에 무슨 뜻인지 한 마디로 풀어 준다**. 덩굴·뿌리째·울타리·김매듯·솎아·두둑·나이테·가지치기처럼 뜻을 짐작하기 어려운 비유는 쓰지 않는다. 한 칸에 비유는 한 번만.
- 옛날 말투·한자어를 쉬운 말로: "형국/구조/연유/대저/하매" 같은 말 금지. "팔자" 는 꼭 필요할 때만.
- **구체 장면**을 1~2개 넣는다(직장·월급·연애·가족·친구·집안일·건강 습관 같은 일상 장면).
- 실천할 수 있는 **작은 행동**을 1~2개 준다(예: "월급날 저축부터 먼저 떼어 두게", "하루 한 번 안부 문자를 보내 보게").

## 4. 칸 구성 (각 칸은 이 순서가 되게)
1) 한 줄 쉬운 요약(이 사람의 강점 또는 흐름) → 2) 왜 그런지 쉬운 설명 → 3) 구체 장면 → 4) 이렇게 하면 더 좋아지는 방법.
칸마다 첫 문장만 읽어도 무슨 이야기인지 알 수 있어야 한다.

## 5. 분량·구분
- 칸(문자열)마다 원문 길이의 **1.2~1.6배**(최소 0.95배, 최대 1.9배). 쉬워지면서 오히려 더 자세해져야 한다.
- 같은 묶음의 여러 조합이 **서로 다른 문장**이어야 한다(격국·일간 차이가 드러나게). 복사해 붙인 듯 반복하지 말 것.
- JSON 구조·키는 원문과 **똑같이** 유지한다. `{` `}` 같은 토큰, `undefined` 금지.

## 6. 좋은 예 / 나쁜 예 (실제 원문 기준)
원문(어렵고 부정적): "돈은 남의 손을 빌리지 않고 제 힘으로 쥐어야 마음이 편한 사람이야. … 새는 구멍은 동업과 형제 같은 벗이야. 같은 나무끼리 한 땅의 물을 나눠 마시니 의리로 빌려준 돈이 돌아오지 않는 일이 잦네. …"
고친 글(쉽고 긍정): "돈은 내 힘으로 직접 벌어 쥘 때 마음이 편한 사람일세. 월급을 받아도 좋지만, 내 이름 걸고 번 돈을 더 귀하게 여기지. 다만 친구나 형제와 돈이 오가면 정 때문에 거절을 못 해 마음이 상하기 쉽네. 돈 거래는 정 대신 종이로 남기고, 내 몫의 통장을 따로 만들어 두게. 그러면 사람도 지키고 돈도 지킬 수 있네."

원문(어렵고 부정적): "편관격이라 거센 일이 몰려도 감당할 만큼만 오니…"
고친 글: "큰 일과 책임이 자주 몰려오는 짜임이라, 어려운 일을 맡을수록 자네 실력이 자라네. 감당 못 할 만큼은 오지 않으니 안심하게. 다만 쉬는 날을 미리 정해 두면 오래 버티네."
