# 토정비결 144괘 — 쉬운 말로 다시 쓰기 (반드시 지킬 것)

사이트: dongnebosal.com (무료 사주·운세). 화자는 **동네보살** — 동네에서 오래 알고 지낸 다정한 할머니/이모 같은 사람.
사용자 지적: **"토정비결이 무슨 뜻인지 모르겠어, 말이 어려워."** 지금 원문은 시적 비유("임금은 밝고 신하는 어진 격", "곳간에 오곡이 산처럼", "뜰 앞 매화가 이슬을 머금고")와 옛말(귀인·혼사·구설·삼가다·섣달)로 가득하다.
목표: **같은 뜻을 일상어로**, 읽자마자 "그래서 올해 나한테 뭐가 어떻고 뭘 하면 되는지" 알게 만든다. 긍정 베이스, 더 자세하게.

## 1. 할 일
입력 JSON은 `{ "괘코드": { title, grade, chongun, months:{1~12} } }` 꼴이다(원문, 옛 말투). 각 괘를 읽고 **아래 새 구조로 다시 쓴다.**

```
"괘코드": {
  "title":   "쉬운 제목 (8~30자, 문장부호 없이 '~해'로 끝나는 꼴)",
  "sum":     "올해 한눈에 — 2문장 (60~200자). 강점·흐름 먼저, 가장 중요한 한 가지 실천",
  "image":   "옛 그림 풀이 — 원문 제목의 옛 그림을 작은따옴표로 인용하고 쉬운 뜻을 풀어 준다 (50~200자)",
  "chongun": "총운 — 올해 큰 흐름을 4~6문장 (250~430자). 원문 총운에 나온 '어느 달이 좋고 어느 달을 차분히 보내라'는 내용은 '음력 5월'처럼 숫자로 살린다",
  "money":   "돈 — 2~3문장 (70~240자)",
  "work":    "일·자리 — 2~3문장 (70~240자)",
  "love":    "사람·사랑·가족 — 2~3문장 (70~240자)",
  "health":  "몸과 마음 — 2~3문장 (70~240자). 병명·진단 금지, 생활 습관(잠·끼니·걷기·쉬기)만. 끝에 '몸이 계속 불편하면 병원에 먼저 가 보게' 류 문구 가능",
  "tips":    ["실천 1 (15~80자, ~게)", "실천 2", "실천 3"],
  "flow":    "g·o·c 12글자 — 음력 1월부터 12월까지 각 달의 분위기: g 좋은 달 · o 무난한 달 · c 차분히 가는 달",
  "months":  { "1": "2~3문장 (85~250자)", "2": "...", ... "12": "..." }
}
```
- `grade`(길·평·흉)는 **출력에 넣지 않는다**(원문 그대로 따로 보관한다). 다만 그 등급의 분위기는 살린다.
- 완성된 예시 두 개가 `examples.json`에 있다(562=길, 311=흉). **말투·풀어 쓰기·분량을 그대로 본뜬다.** 특히 311(흉 괘)이 "차분히 다지는 해"로 어떻게 긍정 재구성되는지 본다.

## 2. 말투
- **보살 말투**: 상대는 "자네", 끝맺음은 `~일세 / ~하네 / ~이야 / ~지 / ~네 / ~군 / ~게(권유)`. 존댓말 어미(`습니다·합니다·입니다·하세요·해요·이에요·예요`) 금지.
- 문장은 짧게(평균 40자 안팎, 85자 넘는 문장은 피하고 105자 넘으면 오류). 한 문장에 한 가지 생각.
- 첫 문장만 읽어도 그 칸 이야기를 알 수 있게 쓴다.

## 3. 쉬운 말 (가장 중요)
- **일상어**만 쓴다. 시적 비유·옛말·한자어를 걷어 낸다. 비유는 `image` 칸에서만(작은따옴표 안에) 옛 그림을 인용하고, 다른 칸에서는 쓰지 않는다(정말 필요하면 아주 쉬운 비유 한 번 + 바로 뜻 풀이).
- 바꿔 쓸 말(예): 귀인→도와주는 사람 · 혼사→결혼 이야기 · 구설→말이 돌고 도는 일(뒷말) · 시비→말다툼 · 송사→법적인 다툼 · 곳간→저축·살림 · 횡재→뜻밖의 돈 · 재물운→돈 흐름 · 신수→한 해 운세 · 액운/탈→어려움·문제 · 경사→기쁜 일 · 삼가다/근신→줄이다·조용히 지내다 · 도모하다→계획하다 · 형통→잘 풀림 · 왕성→넘침 · 음덕→보이지 않는 도움 · 정월·섣달·동짓달→"음력 1월·12월·11월"(총운) 또는 "이달"(월별) · 사방→여러 곳 · 처신→행동 · 임하다→대하다.
- "화(불) 기운의 사람" 같은 말은 "성격이 급하고 불같은 사람", "물 기운의 사람"은 "차분하고 생각 깊은 사람", "쇠 기운"은 "원칙이 센 사람", "나무 기운"은 "부드럽고 자라나는 사람", "흙 기운"은 "느긋하고 믿음직한 사람"으로 풀어 쓴다.
- 방위(동·서·남·북)나 "조심할 사람 유형"이 원문에 있으면 **빼지 말고 쉬운 말로 남긴다**("남쪽으로 멀리 가는 일은 미루게").
- 월별 칸에서는 "1월" 같은 달 이름을 되풀이하지 말고 "이달"이라고 쓴다. 총운에서만 '음력 N월'을 쓴다.
- 구체 장면(월급·가계부·가족 안부·계약서·운전·모임)을 넣고, 작은 행동 하나를 준다.

## 4. 긍정 베이스
- 좋은 점·기회를 먼저, 조심할 일은 **"이렇게 하면 더 좋아지네"** 로 바꿔 말한다. 뜻을 뒤집지는 않는다(원문이 '남쪽 길 조심'이면 '남쪽 먼 길은 미루게'로 같은 사실을 해결책 중심으로).
- 겁주는 말 금지: 위험·흉·불행·재앙·재난·불길·불운·화근·실패·나쁜·망하·이혼·사별·관재·액운 …
- 사람을 깎아내리는 말 금지("복이 없다", "기운이 약하다").
- **흉 괘**도 "차분히 다지는 해 / 때를 기다리며 준비하는 해 / 지키는 데 힘쓰는 해"로 쓰되, 원문이 말한 조심할 일(큰 지출·이동·계약·말다툼 등)은 부드럽게 살려 준다.
- 원문에 없는 **큰 사건**(합격·결혼·사고·질병 진단·이혼 등)을 새로 지어내지 않는다. 원문에 나온 사건만 쉬운 말로 옮긴다. 분야별 칸(money·work·love·health)에서 원문이 다루지 않은 분야는 그 괘의 흐름에 맞는 **일반 생활 조언**(저축 습관, 서류 남기기, 안부 묻기, 잠·끼니)으로 채운다.

## 5. flow (달별 분위기 12글자)
- 각 달 문장의 분위기와 글자가 맞아야 한다: 좋은 소식·기회가 중심 → g, 무난하거나 좋고 나쁨이 섞임 → o, "천천히·미루기·줄이기·말 조심"이 중심 → c.
- 개수 규칙(검사기가 확인): **길 괘** g 5~9개·c 3개 이하 / **평 괘** g 3~6개·c 2~5개 / **흉 괘** g 2~5개·c 3~7개.
- 예: 562(길) `ggogcgooggog`, 311(흉) `ccgcccoooccg`.

## 6. 분량·구분
- 원문 전체 글자 수 대비 **1.1~1.5배**(쉬워지면서 오히려 더 자세하게). 각 칸 허용 길이는 위 스키마와 검사기가 정한다.
- 같은 괘 안에서 같은 문장을 되풀이하지 말고, 다른 괘 문장을 복사하지 않는다. 제목은 144개가 서로 달라야 한다.
- JSON 키는 정확히 위와 같게. `{` `}` 같은 토큰 금지.

## 8. 작업 방법
- 출력은 **Write 도구**로 저장한다(Bash heredoc로 저장하려다 자주 깨진다). 파일은 UTF-8 JSON(들여쓰기 2칸).
- 입력·examples·STYLE·검사기 외 다른 파일은 절대 수정하지 않는다.
- 다 끝나면 마지막에 (1) 검사 결과 한 줄 (2) 고친 예시 1개(원문 → 새 글, 짧게)만 보고한다.
