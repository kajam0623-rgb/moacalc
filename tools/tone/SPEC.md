# 동네보살 원고 말투 바꾸기 — 보살 말투 → 해요체 (2026-10-11 사용자 결정)

사용자: "페르소나가 보살처럼 말하는 것도 그냥 깔끔하고 상냥하게 말하는 걸로 바꾸고, 진짜 사주처럼 알기 쉽게 풀어 얘기해 주는 게 더더더더 필요하고, 중복 내용이 너무 많아."

## 바꾸는 법
- 어미: 보살 말투(`~일세`, `~하네`, `~있네`, `~걸세`, `~하게`(명령), `~지.`, `~야.`, `~어.`) → **해요체**(`~예요/이에요`, `~해요`, `~있어요`, `~거예요`, `~해 보세요`, `~하면 좋아요`).
- 호칭: `자네`, `자네의` → 빼거나 `내`, `나의`, `본인` 쪽으로 자연스럽게. 대부분은 주어를 빼면 된다.
- 옛말·한자 용어(편관, 비견, 용신, 신강, 건록, 일진, 대운 등)는 **쉬운 말이 먼저**. 꼭 필요하면 쉬운 말 뒤 괄호로 한 번만: "책임과 자리의 기운(편관)".
- 비유는 하나만. 같은 뜻을 두 번 말하는 문장은 하나로 합친다(중복 줄이기). 길이는 원문과 비슷하거나 조금 짧게.
- 긍정 베이스 유지: 사람을 약하다·나쁘다고 판정하지 않는다. 겁주는 말 금지(죽음·사고·망한다 등).
- 끝맺음 예: "올해 간판부터 걸어 보게." → "올해는 간판부터 걸어 보세요." / "겁먹을 것 없네." → "겁먹지 않아도 돼요."

## 절대 지킬 것
- **JS 구조 그대로**: 키 이름·배열 길이·객체 모양·주석 줄 바꾸지 않는다(파일 맨 위 주석의 '보살 말투'는 '해요체'로).
- 문자열 안의 `{이름}`·`${...}`·HTML 태그(`<br>`, `<b>` 등)·`\n` 은 개수·위치 그대로 둔다.
- `note` 키(계산 근거 고지)는 이미 존댓말이면 그대로 둔다.
- 다 고친 뒤 `node tools/tone/check.js <파일>` 을 돌려 "OK" 가 나와야 끝. 원본은 `tools/tone/orig/<파일>` 에 먼저 복사해 둔다(검사가 원본과 구조를 비교한다).
