# 띠 궁합 페이지 원고 — 스타일 가이드 (반드시 지킬 것)

사이트: dongnebosal.com (무료 사주·운세). 검색으로 들어온 사람이 "쥐띠와 소띠는 잘 맞나요?"를 궁금해하며 읽는 **안내 글**이다.
화자는 차분한 안내자. 이 사이트의 안내 글(띠·별자리 소개 페이지)과 같은 **존댓말**을 쓴다.

## 1. 말투
- 끝맺음은 `~습니다 / ~입니다 / ~합니다 / ~세요 / ~해 보세요` 같은 **존댓말**만 쓴다.
- 보살 말투(`~일세 / ~하네 / ~이야 / ~지 / ~게 / ~군`)는 이 페이지에서 쓰지 않는다.
- 문장은 짧게. 한 문장에 한 가지 생각. 평균 40자 안팎, 90자를 넘는 문장은 쪼갠다.

## 2. 긍정 베이스 (가장 중요)
- 모든 짝은 **강점부터** 말하고, 어려운 점은 **"이렇게 하면 더 좋아집니다"** 로 바꿔 말한다.
- 어떤 짝도 "나쁜 궁합"이라고 하지 않는다. 충·원진·형도 "속도와 방식이 달라 서로 배울 것이 많은 사이", "말로 확인하는 습관이 필요한 사이"처럼 **할 수 있는 일**로 마무리한다.
- 금지 단어: 위험·흉·불행·재앙·재난·불길·불운·파탄·이혼·사별·실패·나쁜·망하·최악·저주·상극·원수·악연·헤어·깨지·절대·반드시·결혼하면 안·단점
- 사람을 깎아내리는 말 금지: 약하다·약한·약해·약점·얇다·여리다·모자라다·부족한 사람·힘이 없다. → "채우면 좋은 점", "챙기면 좋은 점"으로.
- "~할 운명이다", "~하면 큰일 난다" 같은 단정과 협박 금지. "~하기 쉽습니다", "~하는 편입니다", "~해 보세요"처럼 말한다.

## 3. 쉬운 말
- 일상어로 쓴다. 이 글에서 쓰지 않는 말: 일간·용신·십성·격국·신강·신약·지장간·천간·지지·합화·오행(필요하면 "기운"으로)·상생·상극.
- 관계 이름(삼합·육합·충·원진·형)은 **그 짝의 종류와 같은 것만** 한 번쯤 써도 된다. 다른 종류의 이름은 쓰지 않는다(무난한 짝은 관계 이름을 아예 쓰지 않는다). 관계의 설명은 페이지 틀이 따로 싣는다.
- 두 띠의 이름은 **"쥐띠", "소띠", "호랑이띠", "토끼띠", "용띠", "뱀띠", "말띠", "양띠", "원숭이띠", "닭띠", "개띠", "돼지띠"** 로 쓴다(동물 이름만 쓰지 않는다).
- **구체 장면**을 넣는다(퇴근 후 저녁, 월급날, 여행 계획, 집안일 나누기, 단톡방, 회의, 첫 만남처럼 일상 장면). 어느 짝에나 붙는 일반론을 피한다.
- 각 띠의 성향은 `profiles.json` 의 두 띠 설명(성격·연애·일)에 **맞게** 쓴다. 그 설명과 반대되는 성향을 지어내지 않는다.

## 4. 칸 구성과 분량 (JSON 키 그대로)
짝마다 아래 필드를 가진 객체 하나를 쓴다. 글자 수는 공백 포함.

| 필드 | 내용 | 분량 |
|---|---|---|
| `sum` | 이 짝을 한 줄로: 두 띠의 어울림 또는 흐름 | 45~85자, 문장 1개 |
| `love` | 연애·결혼에서의 모습. 가까워지는 모양 → 서로가 편한 점 → 맞춰 가는 점 | 200~340자, 문장 3~4개 |
| `work` | 일·동업에서의 모습. 역할 분담, 의사결정 속도, 흔한 장면 | 180~320자, 문장 3~4개 |
| `home` | 가족·친구로 만났을 때 | 150~280자, 문장 2~4개 |
| `tips` | 이 관계를 풀어 가는 구체적 행동 3개 | 각 45~110자, 문장 1개씩 |
| `myth` | 이 관계에 대한 흔한 오해 하나를 바로잡는 문장 | 45~100자, 문장 1개 |

- 두 띠 이름이 `sum`·`love`·`work`·`home` 에 각각 **한 번 이상** 나와야 한다.
- `tips` 세 개는 서로 다른 행동(말하기 / 정하기 / 함께하기처럼)이어야 하고 첫 단어가 같으면 안 된다.
- **같은 문장을 다른 짝에 복사하지 않는다.** 78개 짝이 서로 다른 문장이어야 한다. 비슷한 구조는 괜찮지만 문장과 장면은 달라야 한다.
- 첫 문장만 읽어도 무슨 이야기인지 알 수 있어야 한다.

## 5. 관계 종류별로 말할 때
- **삼합 / 육합**: 잘 맞는 이유를 두 띠 성향으로 설명하고, 편하다고 당연하게 여기기 쉬운 점을 한 가지 짚는다(`myth` 는 "합이라고 노력이 필요 없는 건 아니다" 쪽).
- **충**: "정반대라 서로 끌리는 면도 크다"로 시작해, 속도·표현 방식 차이를 구체 장면으로 보여 주고, 역할을 나누거나 거리를 두는 법을 준다. `myth` 는 "충이라고 인연이 아닌 것은 아니다" 쪽.
- **원진**: 큰 다툼이 아니라 **작은 서운함이 쌓이는 모양**을 장면으로 보여 주고, 마음을 말로 확인하는 습관을 준다. `myth` 는 "원진이 있어도 오래가는 관계가 많다" 쪽.
- **형**: "서로 자극을 주고받으며 다듬어지는 사이"로, 말투와 거리 조절을 구체적으로 준다.
- **같은 띠**: 닮은 점이 장점이 되는 장면과, 같은 자리에서 같이 막히는 장면을 둘 다 보여 주고, 서로 다른 역할을 일부러 나누는 법을 준다. `myth` 는 "같은 띠라 다 똑같다는 건 아니다" 쪽.
- **무난**: 관계 이름을 쓰지 않는다. 두 띠 성향의 **조합 그림**(예: 신중함 + 추진력)을 중심으로 쓴다. `myth` 는 "특별한 인연 표시가 없다고 밋밋한 사이는 아니다" 쪽.
