# 일주 그림 · 결과 카드 예시 (img/ilju · img/promo)

사용자가 만든 그림(`C:\Users\닥터원츠\Downloads\동네보살 사진`)을 webp 로 줄여 사이트에 싣는다. 2026-10-02 시작.

- **일주 그림** — '일주 60편 시리즈'(하루 두 일주씩, 갑자부터 순서대로) 그림. 1~24번째 일주는 한 장(`<일주>-anime.png`),
  25번째부터는 세 장(`<일주>-01~03-YYYYMMDD.png`), 갑자는 풍경 세 장(`gapja-upright-tree · tree-water · relationships`).
  → `img/ilju/<일주>-<번호>.webp`. 어디에 놓을지와 그림 설명(alt)은 `content_ilju_img.js`.
  - 1번 그림 = 대표 그림: 일주 페이지 '한눈에 보기' 아래 · og:image · 내 일주 카드(화면 · 저장 이미지)
  - 2·3번은 '드러나는 장면 · 여자와 남자 · 배우자 자리 · 일과 재물 · 조심할 것' 절 끝 가운데 그림 장면에 맞는 곳
- **결과 카드 예시** — 사이트가 만든 결과 카드를 사용자가 저장한 것. 타로 2장 · 이름궁합 1장 → `img/promo/`, 도구 페이지 설명 뒤 '결과는 이런 카드로 저장됩니다'.
- 쓰지 않는 것 — `동네보살-프로필.png`(기존 마스코트 `img/mascot*.webp` 와 같은 캐릭터라 마스코트는 그대로 둔다, 사용자 결정) ·
  `이름궁합.png`(이름 칸이 긴 이름 시험값 — 실린 것은 `이름궁합 (1).png` 의 57점 성장형). 파일 이름만 보고 고르지 말고 열어서 확인할 것.

## 새 그림이 오면

1. 원본 PNG 를 `Downloads\동네보살 사진` 에 둔다(이름 규칙 그대로).
2. `node tools/iljuimg/convert.js` — 새 파일만 바꾼다(`--force` 면 전부). 원본 비율 그대로, 가로 1200 · 정사각 1000 · 세로 900px, 100KB 예산(넘으면 q46 까지 낮추고 폭을 8%씩 줄인다).
3. `content_ilju_img.js` 에 그 일주 줄을 더한다 — `{ at, alt }`, 배열 순서가 파일 번호. alt 는 그림에 보이는 장면만(일주 이름은 빌드가 붙인다).
4. `node build_site.js` — verify 가 데이터와 파일이 1:1 인지, 진짜 webp 인지, 용량을 본다(파일이 빠지면 빌드가 멈춘다).

리포에는 webp 만 넣는다. 원본 PNG(장당 2~3MB)는 Downloads 에만 둔다.
