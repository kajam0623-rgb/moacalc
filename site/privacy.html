핵심 요약

동네보살은 회원가입을 받지 않습니다. 이름, 이메일, 전화번호를 요구하지 않습니다.

생년월일처럼 도구에 입력하는 값은 브라우저 안에서만 계산되고 서버로 전송되지 않습니다. 저장을 선택하신 경우에만 사용하시는 기기의 브라우저 저장소(localStorage)에 남으며, 브라우저 데이터를 지우면 함께 사라집니다.

수집하지 않는 정보

이름, 이메일, 전화번호, 주소, 결제 정보를 일절 수집하지 않습니다. 도구에 입력한 생년월일·급여·대출 금액 등도 서버로 보내지 않으므로 운영자가 볼 수 없습니다.

자동으로 수집될 수 있는 정보

사이트 이용 통계를 보기 위해 접속 기기 종류, 브라우저 종류, 방문한 페이지, 머문 시간 같은 정보가 분석 도구를 통해 익명으로 집계될 수 있습니다. 이 정보로는 개인을 특정할 수 없습니다.

오류 발생 시 문제를 고치기 위해 오류 메시지와 발생 위치가 익명으로 기록될 수 있습니다.

광고

향후 사이트에 광고가 게재될 경우, 광고 사업자가 쿠키를 사용해 이용자의 관심사에 맞는 광고를 보여줄 수 있습니다. 브라우저 설정에서 쿠키를 차단하거나, 구글 광고 설정에서 맞춤 광고를 끌 수 있습니다.

보관과 파기

서버에 개인정보를 저장하지 않으므로 별도의 보관 기간이나 파기 절차가 없습니다. 기기에 저장된 값은 이용자가 직접 브라우저 데이터를 삭제하면 즉시 지워집니다.

이용자의 권리

저장된 생년월일을 지우고 싶으시면 브라우저의 사이트 데이터 삭제 기능을 사용하시면 됩니다. 서버에 보관된 정보가 없으므로 별도의 열람·정정·삭제 요청 절차는 필요하지 않습니다.

문의

개인정보 처리에 관해 궁금한 점이 있으면 문의해 주세요. 확인 후 답변드리겠습니다.

변경 안내

이 방침이 바뀌면 이 페이지에 반영합니다. 중요한 변경이 있을 경우 사이트에 별도로 안내합니다.

자주 묻는 질문

입력한 생년월일이 서버에 저장되나요?

아니요. 모든 계산은 브라우저 안에서 이뤄지며 입력값은 서버로 전송되지 않습니다.

저장된 생년월일을 지우려면?

브라우저의 사이트 데이터 삭제 기능을 사용하시면 즉시 지워집니다.

회원가입이 필요한가요?

필요 없습니다. 모든 도구를 가입 없이 무료로 이용할 수 있습니다.
