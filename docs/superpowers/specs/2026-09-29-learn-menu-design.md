# 명리학 배우기 — 16강 메뉴 (허브 + 강의 페이지 + 내 사주 실습)

## 목적
사이트에 흩어져 있는 명리학 재료(개념 6편, 일간 10, 십성 10, 칼럼)를 하나의 순서 있는 강의로 묶고,
빠진 강의 7편을 새로 쓰고, 강마다 "내 생년월일로 따라 해 보는 실습"과 확인 문제를 붙인다.
- 검색 유입: 강의별 페이지 + 허브(`learn.html`).
- 차별점: 실습이 사이트 엔진(사주 계산)으로 돌아간다. 다른 교재 사이트는 정적 글뿐이다.

## 결정 (사용자 확인, 2026-09-29)
- 방식은 "허브 + 빠진 강의 작성 + 실습" 세 가지를 모두 한다(3번 안).
- 16강 목차(4부): 기초 4강 / 나를 읽기 5강 / 글자 사이의 관계 4강 / 시간의 흐름 3강.
- 새로 쓰는 강의는 1·5·7·9·10·13·16강. 나머지 9강(2·3·4·6·8·11·12·14·15)은 기존 개념·칼럼 페이지를 쓰고,
  그 페이지에 "제 N강" 띠(이전·다음·진도)와 실습·확인 문제를 끼워 넣는다.
- 진도는 "몇 강을 마쳤는지"만 이 기기에 둔다(`dnbs_learn`, 강 번호 배열). 생년월일·시각·성별은 저장하지 않는다.

## 파일
- `content_learn.js` — `learn/*.js` 를 읽어 검증·정렬해 `{PARTS, LECTURES}` 로 내보낸다.
- `learn/NN-*.js` — 강 하나당 한 파일. 공통: `no, part, short, goal, url(기존 페이지) 또는 en(새 페이지), practice, quiz[3]`.
  새 강의는 추가로 `title, crumb, desc, lead, tags, date, sections, tables, faq, related`.
- `learn_client.js` — 브라우저 코드(ES5). 빌드가 `site/learn.js?v=해시` 로 낸다. `core.js` 의 엔진 함수를 그대로 쓴다.
- `hub.html` 엔진: `SJ_JJG`(지장간 표), `sjDaeunStart`(대운 시작·순역행) 추가. 사주 도구도 같은 함수를 쓴다.
- `build_site.js`: `lecturePage`, `learnHubPage`, 기존 페이지에 끼우는 `lectureTop/Bottom`, 사이트맵·llms.txt·RSS·푸터·사전·홈·사주 페이지 링크.

## 화면
- 허브 `learn.html`: 소개 · 진도 막대 · 4부 16강 카드(제목·학습 목표·완료 표시) · 배우는 순서 3단계 · FAQ.
- 강의 페이지: 제목 → 강 띠(제 N강 · 이전/다음 · 진도 점 16개) → 학습 목표 → 본문·표 → 내 사주로 해 보기 → 확인 문제 3개 → 이 강 마쳤어요 → 이전/다음.
- 실습 흐름: 생년월일(·시각·성별) → 재료(내 사주에서 그 강에 쓰이는 부분) → 문제 하나(선택지 4개) → 정답과 풀이 순서.
  풀이는 존댓말, 맞았는지 알려 주는 첫 줄만 보살 말투.
- 확인 문제: 정적 HTML 로 내고(검색에도 글자로 남는다) 스크립트가 채점한다. 답 근거가 엔진으로 계산되는 문제는 verify 가 엔진과 대조한다.

## 강의별 실습
1 네 자리: 사주표에서 "나"를 뜻하는 자리 고르기 · 2 오행: 일간과 같은 오행 글자 수 · 3 천간: 내 일간의 음양 ·
4 절기: 월주가 시작된 절기 · 5 일간: 일간의 오행·음양 · 6 십성: 월간이 일간에게 갖는 십성 ·
7 신강·신약: 돕는 기운 비율 구간 · 8 용신: 필요한 오행 · 9 격국: 내 격국 · 10 지장간: 일지 속 숨은 글자 순서 ·
11 합충: 일지와 월지의 관계 · 12 십이운성: 일간이 일지에서 놓인 단계 · 13 신살: 도화살 유무와 전체 목록 ·
14 대운: 첫 대운 나이(성별 필요) · 15 세운: 올해 하늘 글자의 십성 · 16 종합: 12단계로 한 장 읽기.

## 원고 규칙
- 강의 본문은 존댓말, 실습 첫 반응만 보살 말투. 단정("반드시·무조건") 금지, 사주는 전통적인 해석 체계라고 밝힌다.
- 새 강의는 편마다 사이트 엔진으로 계산한 고유 표를 넣는다(애드센스 "가치가 별로 없는 콘텐츠" 대응 원칙과 같다).
  본문 1500자 이상, FAQ 4개, 내부 링크, 출처가 있으면 표기.
- 학파마다 다른 곳(지장간 일부, 격국·신살 범위)은 "동네보살은 이렇게 셉니다"라고 밝힌다.

## 검증
- `verify.js`: 강의 16개·번호 연속·이전/다음·기존 URL 존재·확인 문제 3개씩·정답 범위·엔진 대조 문제, 지장간 정기 = SJ_BMAIN,
  실습 스크립트 구문, 페이지에 강 띠·실습·확인 문제가 들어갔는지, 허브에 16강 링크.
- `adsense_audit.js`: 새 페이지 본문 800자 이상, 고유율 확인.
- 실제 브라우저: 허브 → 강의 → 실습 정답/오답 → 확인 문제 → 마치기 → 진도 표시, 모바일·PC, 기존 9개 페이지의 끼워 넣은 부분.
- 독립 대조: 실습 정답(십성·십이운성·대운 나이 등)을 엔진과 무관한 공식으로 다시 계산.
