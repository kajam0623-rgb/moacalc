# 동네보살 전면 개편 설계 (2026-09-27)

사주 두 사람 같은 문장 49%→18%, 궁합 네 축이 총점을 따라가던 버그 수정

근거: 국내 서비스 12곳·해외 13곳 벤치마크, 사용자 수요·불만 조사, 라이브 사이트 감사(모바일·PC에서 도구 11개 직접 실행).
조사 원문은 세션 scratchpad `bench/` (kr.md · global.md · users.md · self.md).

## 판정

"무료로 국내 최고"는 된다. 싸우는 자리를 골라야 한다.

- **비어 있는 자리**: 결과 먼저 · 결제 없음 · 근거가 보이는 풀이.
  3강(점신·포스텔러·헬로우봇)은 전부 가상화폐 충전과 결제 유도로 번다. 사용자 불만 1~4위가 광고·결제 벽·복붙 결과다.
  계산 근거를 보여 주는 대중 서비스가 없다. ChatGPT 사주는 만세력부터 틀린다. 우리 엔진은 맞는다.
- **싸우지 않는 자리**: 사람 상담, 앱 푸시 습관, 콘텐츠 물량(포스텔러 6,000건).
- **현재 점수 4.9/10**(점신·포스텔러=10). 엔진은 진짜인데 화면은 "무료 템플릿 운세 + 링크 목록"으로 보인다.

핵심 사용자: 20~30대 여성, 주제는 연애·궁합 → 이직·시기. 방문 피크는 밤 11시~새벽 1시, 연중 피크는 12~2월(신년운세).

## 한 문장 포지션

**"신한라이프만큼 무료, 포스텔러만큼 깊게, 그리고 어디서도 안 보여 주는 계산 근거까지."**

## 원칙

1. 한 사람에게 하루는 하나다. 도구끼리 판정이 반대로 나오면 안 된다.
2. 결과가 먼저다. 광고는 결과 아래에만, 결제 벽은 영원히 없다. 한 번 무료로 연 기능은 잠그지 않는다.
3. 문장마다 이유가 있다. "왜 이 말이 나왔나"를 한 줄로 보여 준다.
4. 생년월일은 서버에 저장하지 않는다. 기기 안에만 둔다. 공유 링크·카드에 생년월일을 넣지 않는다.
5. 나쁜 운은 대처법과 함께 말한다. 불안을 팔지 않는다.
6. AI를 쓰면 표시한다(AI기본법). 지금은 사람이 쓴 원고 + 계산.

## 단계

각 단계는 빌드 → verify → 게이트 → 커밋 → 배포 → 라이브에서 직접 눌러 확인으로 끝난다.

### 1단계 — 신뢰 회복 (깨진 것부터)
- [x] 용어 치환기 오치환("세운 기반"→"올해 흐름 기반", "상관 없이") 차단
- [x] 조사 오류(화성가), 타로 결과의 파란 링크, 역방향 카드를 뒤집어 그리기
- [x] 하루 판정 통일: 생일을 아는 사람에게 띠·별자리 운세가 오늘의 운세와 반대 판정을 내지 않게
- [x] 옛 계산기 45개를 사이트에서 완전히 내린다(페이지 미생성 → 404)

### 2단계 — 첫 화면과 길찾기
- [x] 홈: 모바일 첫 화면에 생일 입력 + 도구 격자. 다시 온 사람에게는 저장된 생일로 오늘 카드를 바로
- [x] 링크 200개 목록은 "사주 사전" 페이지로 옮김. "10 TOOLS·가입 0·검증 250개" 같은 개발자 문구를 사람 말로
- [x] 하단 탭바(오늘 · 사주 · 궁합 · 타로 · 더보기)로 전역 길찾기
- [x] 디자인 한 벌: 주 버튼 금색, 공유·저장·PDF 금테 한 벌, 각주·소제목 설명 13px (점수 막대 색은 값에 따른 표시라 유지)

### 3단계 — 입력과 개인화

- [x] 궁합에 두 사람 성별(캐릭터 그림용, 점수와 무관)
- [x] 사주 이름(호칭) 입력 — 궁합 태어난 시각은 넣지 않음: 궁합 네 축이 연·월·일주만 쓰고 칼럼·FAQ도 "생년월일만"으로 안내해 왔다

## 미룬 것과 이유
- **타로 마이너 56장**: 카드 그림 56장 + 카드마다 자리 9·고민 16개 풀이(현재 22장 기준 약 1,400문단)가 필요하다. 그림 없이 글만 넣거나 풀이를 얇게 넣으면 애드센스가 문제 삼는 "찍어 낸 얇은 페이지"가 56개 늘어난다. 승인 뒤 그림과 원고를 갖춰 한 번에 넣는다.
- **꿈해몽·토정비결**: 둘 다 사전형 대량 페이지라 같은 이유로 승인 뒤. 토정비결은 144괘 원문 해석 원고부터 필요.
